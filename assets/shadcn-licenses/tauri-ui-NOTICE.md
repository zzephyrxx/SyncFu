tauri-ui / create-tauri-ui
https://github.com/agmmnn/tauri-ui

Upstream declares the MIT license in packages/create-tauri-ui/package.json.
The upstream project delegates UI component generation to the official shadcn/ui
CLI. SyncFu follows this Tauri + Vite + shadcn desktop composition, adapting the
existing application rather than replacing its native backend with a scaffold.

Reference snapshots and their hashes are recorded in
docs/shadcn-redesign/sources.json. Vendored shadcn/ui component code is covered by
the complete shadcn-MIT.txt license distributed alongside this notice.
