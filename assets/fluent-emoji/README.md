# Fluent Emoji device avatars

Ten unmodified 256 × 256 3D PNGs from [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji), used locally by the production device list, device editor and sync endpoint avatars. No runtime network requests.

Source revision, original paths, download URLs and SHA-256 checksums are recorded in [sources.json](sources.json). Copyright Microsoft Corporation; [MIT license](LICENSE.txt). Custom emoji outside this small local set use the platform emoji font.
