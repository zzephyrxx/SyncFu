# Focus 性能验证（2026-11-14）

## 口径

同一台 macOS 开发机、Rust release、临时目录、回环 TLS；每个变体同样的三个用例，单线程串行运行两遍。不是 Windows 实机、LAN 吞吐或跨设备验收。样本少，报告范围，不作普遍保证。

| 指标 | 原基线两次 | 最终 strip + thin LTO 两次 |
|---|---:|---:|
| 10001 文件首次精确扫描 | 274.15–275.05 ms | 184.75–190.30 ms |
| 未变化时精确扫描 | 284.02–284.30 ms | 188.13–203.70 ms |
| 1% 内容变化时扫描 | 284.88–301.20 ms | 194.02–202.26 ms |
| 所选 100 项同步 | 3.288–3.320 s | 2.633–2.667 s |
| 128 MiB 文件传输 | 1632–1636 ms | 1536–1538 ms |
| personal 方向策略往返 | 主要 1 ms，少数 3 ms | 均 1 ms |

按两次平均值估算：首次扫描约减少32%，100项同步约减少20%，128MiB传输约减少6%。不是承诺实际两台电脑有相同比例提升。

## 实现与安全条件

1. 最多4个有界扫描 worker，重复使用128KiB缓冲，每个文件仍完整 SHA-256；目录权限句柄与 no-follow 不变。
2. 传输片段256KiB→1MiB，减少请求往返；两端 encoded/raw 上限一致，协议升级为4；最终文件指纹/写前验证仍保留。
3. 独立双端只读 preflight 并行，移除没有竞争批次时紧邻 Begin 的重复预检；Engine::begin 仍权威验证。存在竞争批次先完成准入再仲裁；精确重复仍校验 frozen work。
4. release 剥离符号及 thin LTO，不用缩减哈希、跳过备份或信任时间戳换速度。最终测量没有显示100项同步回退。

正确性由当前 core 全量测试保护，新增传输最大片段+余数/超限测试；具体结果见 Focus 交付报告。原基线、三轮变体和最终日志全部保留在此目录。

## 重现

```bash
cargo test --locked --release -p syncfu-core --test sync -- --ignored --nocapture --test-threads=1
```

再次运行同一条命令取得第二次测量。运行期间不要同时构建其他 target 或修改测试数据；调试构建结果不能与此表比较。
