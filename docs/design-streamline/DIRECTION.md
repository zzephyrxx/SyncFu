# SyncFu 核心界面：双槽交换台

2026-11-14 用户批准后实施。本轮不再使用 FigCraft；历史 `.figcraft`/PNG 仅作为早期探索保留，不是当前设计依据。

## 设计契约

任务：选任务、看变化、决定必要冲突、确认同步。唯一主要动作在底部；总览和交接进入更多工具，不删除既有能力。

- 设备形成固定左右的双槽装置，中间直接选择双向/单向/镜像。方向改变不交换设备位置；只有后端提交成功才改变已选状态。
- 文件名为主行，父路径独立次行；全路径可键盘展开，同名项即使关闭路径偏好仍可区分。
- 版本比较使用右侧抽屉；最终同步预检在底部展开回执，不覆盖列表。高风险删除必须明确批准。
- 打开当前在线任务、策略提交、重连时进行一次只读检查；失败不自动重试。没有 P3 自动写入。
- 雾白 #F3F6F8、瓷白 #FFFFFF、墨蓝 #172B36、群青 #3155DB、小面积橘红 #F9774B、钢灰 #62717C。深色独立令牌，语义状态不用颜色单独传达。
- 使用系统字体、Radix/Lucide/Motion 与本地 Phosphor 文件图标。不引入整套新 UI 框架或大型字库。反馈动效遵守系统减少动效。

## 可验证约束

1120×780、1440×900、680×560 为桌面目标；390×844 为浏览器降级检查。1120 默认屏幕至少 6 条完整文件行；主操作保持可见；确认区不得覆盖工作区末行。键盘焦点/弹层返回、五语言与深浅色验证见 `evidence/`。

正常正文和路径对比度最低 4.5:1；实际浅色初测：正文14.63、路径5.03、端点辅助4.64、主按钮6.08。其他主题/状态以验证记录为准。

## 模式来源

沿用原项目已选取的交互模式，不下载运行外部组件：
- Radix segmented single-choice：方向选择。
- Radix Dialog：模态焦点/恢复，使用桌面抽屉样式。
- Fluent Toolbar/List：主次信息、低频命令溢出。
- 现有 SHA-256 计划/策略/批准/备份内核：UI 精简不改变写入授权。

## 证据边界

浏览器证据使用 DEV-only `DesktopHarness`，不连接本机命令、不操作实际文件。Rust 临时目录/回环测试验证真实内核。两者都不能替代 Windows/macOS 实体 LAN 双机验收。
