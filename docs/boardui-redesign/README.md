# SyncFu BoardUI 核心工作台

## 交互约定

当前交互约定：单张操作清单；新增/更新/删除类型勾选卡；默认勾选非冲突新增和更新；危险操作才再次确认。浅/深两套纯色主题，原Logo不改，界面无渐变、玻璃、新拟物或材质选择。

正式入口使用实际BoardUI组件源码。`CheckboxCard`、Checkbox、Button及React Aria Table原始组合被保留，Table客户演示被替换为真实Plan，原有渐变选中填充改为纯色。图标通过Morphicons渲染少量Lucide IconNode；Microsoft Fluent Emoji仅用于空状态和连接等辅助场景。没有复制BoardUI的账号/Pro/AI/chat功能，也没有引入Next运行时。

## 操作规则

- 三类卡片是选择开关，不是立即执行按钮；部分选择显示mixed。
- 初次检查选中新建/更新；删除和未解决冲突默认不选。
- 类型卡、表头全选作用于所有匹配页，不仅屏幕上的50行。
- 本次范围只影响发送/接收选择，不改任务长期方向；缩小范围剔除范围外勾选，放宽范围不偷偷恢复勾选。单向规则自动约束本次范围。
- 搜索不更改规则；隐藏但已选的项目有数量提示和“查看已选”入口。
- 普通项：一次点击、一次preview、最多一次execute；仍有内容/权限/备份检查。
- 删除、所选冲突覆盖、撤销、风险或后台扩展选择：先显示真实清单再确认；风险批准仅对应那份payload。
- 在预检期间暂停可以否决后续执行；恢复暂停只触发只读检查，不自动写入。

## 真实范围与已知限制

浏览器使用DEV-only transport，不操作真实同步目录。Rust测试使用临时目录与回环节点；两者都不是实体Windows/LAN验收。macOS包只做本机构建与ad-hoc完整性签名，不是Developer ID公证。原生WKWebView视觉、Windows本机构建/安装体积、实体双机尚未验证。

生产入口不加载旧Material/P0演示，旧演示仅在DEV可访问。React Bits经过评估但未复制受限源码；趣味反馈由Morphicons和已有的真实配对滚轮完成，不增加无业务用途的交互。当前Vite对约655KB的桌面JS块给出拆分建议，构建成功；未通过提高阈值隐藏该提示，也不宣称已经完成启动性能专项测量。

历史材质源码/文档只作迭代记录，不是当前UI证据。Windows默认仍采用轻量WebView2 bootstrapper，离线运行时包需显式选择。
