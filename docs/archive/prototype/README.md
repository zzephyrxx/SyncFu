# P0 第一版归档

> 当前原型已升级为第二版。请阅读 [P0 第二版：桌面传送台](v2/README.md)。下文和本目录旧截图保留为第一版历史证据；语言/外观等偏好现在独立本地保存，不再全部随刷新丢弃。

## 边界

原型入口：`/?prototype`。原有入口 `/` 和只读旧界面示例 `/?preview` 不变。
所有设备、目录、内容、同步、备份、核对与撤销都是虚构演示；原型代码不调用 Tauri、网络或文件系统接口。状态只在内存中，刷新/切换场景重置。深浅色仅在当前页面生效，不修改正式应用偏好。

这不是已完成的同步引擎升级。P1–P3 的协议、权限校验、自动调度、删除风险评估和真实备份仍需后续实现。

## 设计契约

- 使用者：个人双机工作者及非技术用户；多设备仍是独立一对一任务。
- 核心任务：看清两个目录及方向，审阅/决定变化，开启任务级自动模式，准确知道还有什么未处理。
- 首屏：紧凑任务侧栏、当前任务名称、双端目录与方向、触发方式、文件变化及一个对齐的执行操作区。
- 视觉锚点是“两端目录之间的方向轴”，不是大数字或装饰卡片。所有内容左对齐；仅空状态和状态图形居中。
- 配色沿用现有设计令牌：近白画布 `#fafafb`、面板 `#ffffff`、石墨文字 `#222228`、次级文字 `#62626d`、品牌紫 `#633ad6`、结构线 `#dedee4`。风险/成功继续用现有语义色，不用品牌色表示危险。
- 字体：原生系统无衬线字体用于界面；仅内容比较使用等宽字体。正文 12–13px，主标题 25px，次级标签 10–11px，依靠字重/间距而非巨大标题分层。
- 内容区域最大 1060px；默认侧栏 218px，窄桌面收为图标栏，任务名仍在详情和按钮可访问名称中显示。操作栏贴合文件清单，不覆盖文件。
- 相对旧界面的修订：配对入口移到新建/设备；移除主视觉一致率；主要操作只出现一次；三种不处理语义分开；安全提示不依赖隐藏帮助。
- 设计复核：不用通用营销 hero、KPI 卡片或无意义动画，保留原项目品牌而不重塑成另一款 SaaS。唯一强化元素是有业务含义的方向轴。
- 视口：1120×780、680×560、1440×900；额外窄屏兜底不代表移动端产品承诺。浅深色、长路径、键盘焦点、减少动画需实测。

## 可以体验的流程

1. 默认“研究资料”：筛选、搜索、勾选普通变化；比较 Markdown 冲突及二进制元信息；选择一端覆盖或三种不处理方式；查看与撤销忽略/排除。
2. “任务规则”：切换双向、单向更新、单向镜像及源端；开启/关闭“有改动自动同步”。原型仅改变示例规则，不运行真正 watcher。
3. “项目归档”：删除保护阻止执行，核对清单并明确批准一次后才允许演示执行。
4. “演示备份并同步”：确认后模拟三个阶段；普通文件完成但冲突保留。历史中的演示撤销会恢复样例变化并暂停任务，防止立即重做。
5. “新建任务”：示例连接 → 等待对端授权 → 方向/触发/信任 → 确认；不触发系统文件选择。
6. “准备切换电脑”：选任务并检查，未处理、离线、风险、暂停均不能假报带齐。
7. 顶部场景：文件一致、离线、首次使用、权限不足、中断核对、他人共享接收端。切换会清空本轮示例。
8. 设备、历史、设置、任务重命名/暂停/移除均可交互；配置导出明确标记为后续实现。

## 状态约束

| 状态 | 触发 | 反馈 / 安全下一步 |
|---|---|---|
| 加载 | 重新检查 / 演示执行 | 有限阶段状态，结束后可继续审阅，不编造百分比 |
| 空 | 首次使用 / 无变化 / 搜索无结果 | 新建 / 文件一致示例 / 清除筛选 |
| 错误 | 离线 / 权限不足 | 明确归属，模拟重连/重新授权，不当作源目录清空 |
| 部分完成 | 中断场景 / 正常文件完成但仍有冲突 | 核对结果 / 保留待决定 |
| 成功 | 演示完成 | 明确实际文件未改变，可查看历史与演示撤销 |
| 权限 | 共享接收端 / 等待对端授权 | 禁止修改规则及反向决策，允许本机暂停 |

## 本地验证

构建使用现有命令 `npm run build`。启动使用 `npm run dev` 后打开 `/?prototype`，或通过 `.claude/launch.json` 的 `syncfu-prototype`。

原型模型测试无需新增依赖；在支持 TypeScript 类型擦除的 Node.js（22.18+ 或更新版本）运行：

```bash
node --test scripts/prototype.test.mjs
```

测试不代表真实双机协议/同步能力已验收。

## 实测结果

- TypeScript + Vite 构建通过；原型模型/隔离测试 **12/12 通过**（本机 Node v26.13.0）。
- 已在浏览器实际走完：新建三步、冲突选择、版本忽略/路径排除、演示同步、历史撤销并暂停、删除批准和交接未完成提示。
- 已核验共享接收端规则不可改、允许按固定源端规则获取更新；离线、权限不足、中断等场景有安全入口。
- `1120×780`、`680×560`、`1440×900` 实际截图，含深色和长中英文名称。执行区独立占行，不覆盖工作区。
- `/` 原连接页与 `/?preview` 原示例页浏览器冒烟通过；与源码归档比较，现有业务源码/Rust 内核未变。
- 浏览器错误日志为空。Escape 关闭/焦点返回与基本名称检查通过；未做完整 WCAG 或屏幕阅读器审计，减少动画只核验样式规则，未模拟系统媒体偏好。
- **未验证/未实现：** 真实桌面壳、Windows/macOS 双机、新协议与权限后端、真正自动调度/删除熔断/备份恢复。本轮没有重跑 Rust 测试，也没有新增依赖。
