# P0 第二版：桌面传送台

入口：[http://localhost:1420/?prototype](http://localhost:1420/?prototype)。本地预览服务需保持运行；也可用项目现有 `npm run dev` 启动。

**这是可交互原型，不是真实同步引擎的新版本。** 所有设备、目录、配对码、文件内容与统计都是示例，不连接真实设备、不读写同步目录。任务、历史和统计只在本轮内存中；刷新重新载入样例。外观和语言等偏好仅保存在 `syncfu-prototype:v2:preferences`，不会修改正式应用偏好。

## 本轮交付

- **视觉**：冷白/石墨色基础、较大的设备图形、14px 文件正文、12–13px 辅助标签，减少重复说明。两端设备与连接居中，文件/表单保持阅读对齐，执行区独立占行。
- **素材**：同系列 Microsoft Fluent Emoji 3D 笔记本、台式机、文件夹、盾牌，本地打包共 113,838 字节，MIT 许可与内容指纹保留于 [素材说明](../../../assets/prototype/README.md)。不开启 WebGL、无 CDN 热链。
- **配对**：设备 → 连接设备。五列数字依次滚动停靠；刷新立即作废旧状态，生成期间不能复制；停稳才开始有效期。支持等待/发起两种演示、前导零、过期状态、复制失败提示、关闭重开。配对码不能用于真实连接。
- **总览**：近 7/30 天同步次数、传输量、文件处理次数；每日传输量单系列柱图、鼠标/键盘提示、等价数据表。统计由示例记录和本轮完成操作计算，不是写死的标签。
- **设置**：语言、新手模式、启动页、主题、密度、强调色、3D 开关、动效、新任务默认方向/自动开关、普通同步确认、成功提示、统计开关及重置。备份天数/额度明确为尚未接入后端的预设，非法输入不会覆盖有效值。
- **新手模式**：默认关闭。开启后显示帮助；关闭不隐藏删除、覆盖、权限、错误和确认的关键后果。
- **五语言**：简体、繁体、English、日本語、한국어，覆盖导航/状态/设置/弹窗/可访问名称及日期数字。文件名、设备名、路径和文件示例内容属于用户数据，不自动翻译。切换语言保留当前任务、选择、筛选和搜索。
- **核心流程**：保留三种方向、指定版本覆盖、稍后/当前版本忽略/路径排除、删除核对、共享端权限、执行/历史/撤销暂停与交接检查。选版后的动作直接显示覆盖哪一端；确认箭头遵守实际方向；忽略内容不谎报一致，交接不自动反转规则。

## 建议体验顺序

1. **设备 → 连接设备 → 生成新码**：观察五列滚动，再试发起连接与前导零输入。
2. **使用总览**：切换 7/30 天、点击数据表；在任务中演示完成一次同步，再回来看统计。
3. **设置**：切语言、浅深色、密度、3D/动效，刷新确认偏好保留；打开新手模式比较信息密度。
4. **设置 → 同步默认值** 后新建任务：向导应继承默认模式与自动开关。目录授权仍需明确模拟批准。
5. **研究资料 → 比较并决定**：选版后审阅，再确认同步；未决定项仍保留。
6. **项目归档**：103 项删除默认阻断，勾选核对后仅批准这次清单，执行前仍需确认。
7. **历史 → 撤销**：任务保持暂停，避免立即自动重做。
8. 顶部场景切换到离线、权限不足、中断、共享接收端、首次使用；这些场景不允许危险按钮绕过限制。

## 数据口径与安全边界

- 成功、非空的同步批次计一次；失败、取消、撤销、空操作和重复记录不增加同步次数。
- 传输量只含新增/更新/已选冲突版本的内容，不把删除前文件大小当传输，也不把同一传输在两端记两次。处理文件数是累计处理次数，并非去重文件数。
- 关闭统计后，新演示仍可留下撤销历史，但不继续累计使用统计；重新打开不会补计关闭期间的操作。
- 清空统计只影响本轮样例，不清任务或历史；刷新会重新载入示例数据，确认框明确说明这一点。
- 普通成功消息可以关闭，安全警告不可关闭。关闭普通确认也不能绕过覆盖/删除确认。
- 系统减少动画优先于应用动效设置；低性能设备不播放非必要空间动画。关闭动效后滚轮直接显示最终值，复制仍受最终状态限制。
- 真正的协议、任务权限、自动调度、备份及删除熔断仍按 [完整升级路线](../../upgrade-plan.md) 的 P1–P3 后续实现；这里不能替代 macOS↔Windows 真双机验收。

## 验证结果

- `npm run build` 通过。
- `node --test scripts/prototype.test.mjs scripts/prototype-v2.test.mjs`：**27/27 通过**。
- 单元覆盖：旧核心模型、五语言键/占位符、偏好校验与存储拒绝、配对状态/过期/旧回调、统计范围/去重/删除字节/撤销、交接方向和本地暂停、素材指纹。
- 浏览器实际走过：新建授权、默认规则继承、文本/二进制冲突、三种不处理、选版执行、历史撤销暂停、103 项删除确认、只读共享端、离线/权限/中断、交接阻断。
- 统计实测曾从 13 次/645 项增长为 14 次/651 项；关闭统计后历史仍可新增而统计不变。数值会随样例日期/本轮操作变化，不保证截图永远为该数。
- 复制参数与最终显示码一致、复制拒绝的恢复路径已通过 mock API 测试，未读取或修改用户真实剪贴板。滚动期间关闭不重新弹出。
- 7/30 天表格与图形可切换，键盘 focus 可显示值，提示框位于图表内，不裁掉文字。
- 已核验 680×560 英文、1120×780 浅色和 1440×900 深色日文；无文档级横向溢出，执行栏不覆盖工作区。小窗口需滚动查看完整清单。
- 浅深图表配色通过 dataviz 验证：`#6250d6` / 白色，`#9085e9` / `#20232c`。
- 未做完整 WCAG/屏幕阅读器审计；系统减少动画优先级有单元测试，但未通过系统设置真实切换媒体偏好。未实际等待完整 60 秒验证浏览器倒计时过期；过期边界由可控时钟状态测试覆盖。
- 本轮未重跑 Rust 测试、未制作桌面发行包或重新双机测试。

## 设计依据与取舍

参考 [Raycast 官方设计复盘](https://www.raycast.com/blog/a-fresh-look-and-feel) 的关键图标、层级和上下文操作；3D 素材来自 [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji)，并非随机混用多个材质库。唯一新运行依赖是 `motion`，原型 chunk 为按需加载，正式入口不加载这一分支。

本版更有表现力，但不把每个图标都做成循环动画。独特交互集中在滚轮配对和工作设备之间的传送关系，其余保持安静。最终视觉偏好仍需用户体验确认，不以自动测试“证明高级感”。
