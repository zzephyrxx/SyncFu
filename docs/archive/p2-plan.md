# P2 实施边界

P1 源码指纹已核对，检查点：`artifacts/SyncFu-before-P2-verified-xtoWDN`。

- 新增真实冲突比较、按稳定设备 ID 选择版本、批量决定、稍后/当前版本忽略；路径排除复用双方策略协商。冲突决定必须来自有管理权的认证端，绑定原始双端内容、策略与基线，并进入既有备份/风险/撤销链。
- 比较只读取授权根下、指纹匹配的普通文件；每端最多 256 KiB，UTF-8 文本可只读对照，二进制/超限回退元信息，不执行文件内容。
- 本端审阅偏好（稍后/当前版本忽略）持久化并显示作用域，不修改共同基线；任一端内容/策略变化时失效。共享接收者不能替所有者批准覆盖。永久排除属于任务策略，需双方确认并使旧计划失效。
- 选择执行前由后端补齐必要父目录/目录删除依赖，返回最终选择与风险；UI 按该清单确认，不悄悄增加操作。
- 正式入口采用第二版视觉，新建/配对/策略确认/目录授权/检查/冲突/执行/历史/撤销/设置全部使用真实命令。原型独立保留；真实界面没有示例设备、示例统计、伪造配对成功或虚假自动同步。
- 使用统计由已核验完成记录计算，关闭后不新增统计，清空不删除撤销历史。真实备份设置接原有命令；P3 自动功能明确尚未运行。
- wire protocol/schema 升级为 3，P1 数据保守迁移；旧 Work 可核对，不可借缺省冲突授权放宽写入。所有临时写入测试在隔离目录/回环节点内，绝不自动打开用户实际数据。
- 测试：冲突覆盖/删改冲突、越权/过期/结构冲突/预览限额、忽略再出现/重启、父子依赖、备份撤销保护、真实界面状态与 async 竞态。沿用 Rust 测试、生成契约 --check、Clippy、桌面编译、前端测试，补浏览器可交互的 fake-adapter 集成场景。

不提前实现 P3 自动调度、公网连接或 P4 配置迁移。开发结束如未有实体双机环境，明确报告未实测，不能以浏览器或回环替代。
