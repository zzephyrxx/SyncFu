# Focus 本轮交付与验证

## 已实现

- 双槽任务工作台，常驻方向选择，保留镜像/换源确认、首次互信协商与共享 owner 权限。
- 文件名优先、父路径次行、完整路径键盘可展开；同名项保留目录区别。分页避免一次渲染万条记录。
- 冲突侧边审阅、原位同步预检/确认回执、部分结果/撤销反馈。
- 进入当前在线任务、策略提交、重连的一次只读检查；失败无自动重试循环。仍无 P3 自动写入。
- 总览/换机准备收进更多工具；新任务集中表单，创建成功而规则失败时保留任务、不重复创建。
- Windows 默认轻量 WebView2 bootstrapper，离线版显式选择；release strip + thin LTO；本地素材许可随包提供。
- 协议4 / schema3；普通应用身份与验收身份分开。

## 包体说明

已去除默认Windows整份离线WebView2运行时；缺运行时的电脑首次安装需要联网，不能称为完全离线包。Mac universal可执行文件本轮约30.8MiB，旧验收版约41MiB；最终ZIP/应用文件总大小见交付目录的 `ARTIFACTS.json`，不把Mac大小当Windows大小。
